Tentang Saya

Saya adalah Raya Sobarul Muttaqin, mahasiswa program studi Sistem Informasi di Universitas Gunadarma (Angkatan 2024). Saya memiliki ketertarikan mendalam pada bagaimana teknologi informasi, pemrograman terstruktur, dan manajemen basis data dapat diintegrasikan untuk menyelesaikan permasalahan bisnis maupun operasional secara efektif.

Selama menempuh perkuliahan, saya aktif mendalami pengembangan web front-end dan back-end, perancangan skema database menggunakan MySQL dan Oracle SQL, serta pemodelan analisis data dan algoritma. Saya terbiasa bekerja dengan ketelitian tinggi, cepat beradaptasi dengan teknologi baru, dan antusias berkolaborasi dalam tim pengembangan perangkat lunak.
